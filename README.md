# NovaBank v8.0.0 – Staff Banking & Payroll Edition

An additive upgrade to the uploaded NovaBank Super Admin Portal v7. Retains the existing fictional banking simulator and adds the first Payroll Control Centre foundation.

See `PATCH_NOTES.md` for exact functionality, limitations, data-safety notes, validation and deployment steps.

**Keep the existing Cloudflare D1 database and `wrangler.toml`. Do not reset or recreate the database.**

NovaBank is a fictional banking simulator. It is not a real bank and does not provide real deposits, loans, payments, cards, currency, payroll services or financial instruments.
